# PATHWAYS · 채용 플랫폼 공고 묶음 추가판

기업 채용관을 그대로 유지하면서 LinkedIn·원티드·사람인·잡코리아·점핏 공고를 **플랫폼 공고** 메뉴로 분리한 정적 웹사이트입니다.

## 실행

ZIP 압축을 풀고 `index.html` 또는 `pathways-jobs.html`을 브라우저로 여세요. 상단 **플랫폼 공고** 또는 홈의 **채용 플랫폼 공고, 별도 묶음으로 보기**를 누르면 됩니다. `index.html#/platforms`로도 바로 접근할 수 있습니다. 이 파일은 공개 URL로 배포하지 않았습니다.

`cs-career-roadmap-v2.html`은 기존 파일을 그대로 포함했습니다. 연결된 직무·준비 경로를 사용하려면 같은 폴더에 두세요.

## 메뉴 구성

- 기업 공고: 기존 기업 채용관·대학 보조 출처의 21건(마감 참고 1건 포함). 과거 데이터 확인일 2026-11-07을 유지했습니다.
- 플랫폼 공고: 별도 추가한 10건. 2026-11-08에 공개 원문을 열람했습니다. LinkedIn 2건, 원티드 4건, 사람인 1건, 잡코리아 1건, 점핏 2건입니다.
- 기업 채용관: 기존 17곳. 플랫폼에서만 발견한 기업을 공식 채용관으로 추가하지 않았습니다.
- 저장한 공고: 두 출처의 관심 공고를 함께 저장·비교하고 체크·메모·지원 상태를 관리합니다.

플랫폼 공고는 본문 확인 8건, 일부 항목만 확인한 공고 2건입니다. 사람인 티피씨 공고와 잡코리아 코스윌 공고는 상세 담당업무가 확인되지 않아 이를 표시했습니다. 확인된 학력 등 일부 조건을 전체 필수요건으로 표현하지 않았습니다.

## 수록 목록과 외부 원문 목록

출처 버튼과 검색·경력·분야 필터는 **이 파일에 수록된 공고**에만 적용됩니다. 아래 **플랫폼 원문에서 더 찾아보기**는 각 플랫폼의 공고 목록을 새 탭으로 엽니다. 이 두 목록은 별개입니다.

개별 카드에는 출처, 원문 확인일, 확인 수준, 원문 링크가 있습니다. 로그인·접근 제한·삭제·조기 마감이 있을 수 있으며 최종 지원 조건은 해당 원문에서 확인하세요. 10건이 플랫폼 전체 공고라는 뜻이 아니며, 새로고침할 때 새로운 공고를 수집하지 않습니다.

## 기존 기록을 옮기려면

기존 버전에서 먼저 **내 기록 백업**을 하세요. 수정본의 **출처·업데이트 기준 → 기록 복원**에서 JSON을 불러오면 됩니다. 기존 21개 공고 ID와 저장소 키를 유지했습니다. 다만 로컬 HTML의 저장소는 파일 위치·브라우저에 따라 달라질 수 있으므로 자동 이전을 보장하지 않습니다. 복원은 기존 지원 기록을 교체합니다.

## 한계

이 버전에는 백엔드, 자동 수집·갱신, 실시간 지원 여부 확인, 로그인 연동, 자동 중복 병합이 없습니다. 기존 기업 공고를 이번에 재검증한 것은 아닙니다. 표시된 종료일 경과만 브라우저 시계로 계산하며, 일정 변경이나 삭제는 자동으로 알지 못합니다.

개인 구직 탐색을 위한 핵심 정보 요약과 링크이며 공고 본문 전체를 복제하지 않았습니다. 대량 수집이나 공개 서비스 연동을 추가하려면 출처별 허용 범위와 권한을 따로 확인해야 합니다.

## 수정·재생성

`jobs-data.json` 또는 `src/app.js`, `src/styles.css`를 수정한 뒤 `python3 build_site.py`를 실행하면 단일 HTML 두 파일이 생성됩니다. 단순 사용에는 Python이나 설치 작업이 필요 없습니다.

신규 플랫폼 공고는 `sourcePlatform`(linkedin/wanted/saramin/jobkorea/jumpit), `sourceScope`(실제 확인한 범위), `verifiedAt`을 포함합니다. 기업 공고는 `sourcePlatform`을 넣지 않습니다. 플랫폼 확인일 `platformUpdatedAt`과 기존 기업 확인일 `updatedAt`을 분리했습니다. 새 기업·분류 추가는 JSON 원본을 수정해 재생성하세요. 브라우저 JSON 불러오기는 이미 정의된 기업·분류 ID만 허용합니다.

`PLATFORM-SOURCES.md`: 새 공고의 원문과 확인 범위. `SOURCE-NOTES.md`: 이전 기업 공고 출처 기록. `QA-NOTES.md`: 기능 검증 범위. `README-previous.md`: 기존 버전의 상세 안내.
